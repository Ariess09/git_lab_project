# Git Lab Project

## 📌 Project Description
This project was created as part of a Git and GitHub lab assignment. 
It demonstrates how to create a local repository, connect it to a remote GitHub repository, 
track changes, commit updates, and synchronize files between local and remote repositories.

## 📂 Project Structure
The project contains the following files:

- index.html
- page1.html
- page2.html

These HTML files demonstrate basic webpage structure and linking between pages.

## 🚀 Technologies Used
- HTML5
- Git
- GitHub

## 🔧 Git Commands Used
During this lab, the following Git commands were used:

- git init
- git add .
- git commit -m "message"
- git remote add origin <repository_link>
- git push -u origin main
- git pull origin main
- git branch
- git status
- git log

## 🌿 Branching
The project uses the main branch as the primary development branch.

## 📖 Learning Outcomes
Through this project, I learned how to:
- Initialize a Git repository
- Connect a local repository to GitHub
- Stage and commit changes
- Push changes to a remote repository
- Pull updates from GitHub
- Manage branches
